# Southern Sports Daily

An AI-powered college sports article generator.

## How to upload to GitHub and deploy on Vercel

### Step 1 — Upload to GitHub
1. Go to github.com and sign in
2. Click the green "New" button to create a repository
3. Name it "southern-sports-daily", leave everything else default, click "Create repository"
4. Click "uploading an existing file"
5. Drag the entire "southern-sports-daily" folder into the upload box
6. Click "Commit changes"

### Step 2 — Deploy on Vercel
1. Go to vercel.com and sign up with your GitHub account
2. Click "Add New Project"
3. Find "southern-sports-daily" in the list and click "Import"
4. Leave all settings as default and click "Deploy"
5. Your site will be live at a URL like southern-sports-daily.vercel.app

### Step 3 — Add your domain (optional)
In Vercel, go to your project settings → Domains → add your custom domain name.
